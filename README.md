## 🤖 AI-Assisted Development

I build with AI coding agents, and I keep the work structured instead of "vibe coding":

- **Spec-driven workflow:** the horse and medical-equipment projects were built with Spec Kit (spec, plan, tasks, implement). The `specs/` folder in each repo shows the process.
- **Project rules for Claude Code:** each repo carries a `CLAUDE.md` with the API contract, folder layout and conventions, so the agent follows the same rules on every task.
- **Custom skills:** [speckit-claude-skill](https://github.com/mamdouh19952/speckit-claude-skill) and [php-laravel-claude-skills](https://github.com/mamdouh19952/php-laravel-claude-skills).
- I review and understand the code the agent writes, and I own the architecture and the decisions.
